# Source provenance

The repository was created by history-filtering the reusable Builder and
Runtime paths from:

- source repository: `spacefast/monorepo`
- source checkout head: `a3dfdac4529306847261ed3dd57dd1f816a35192`
- Rust cutover source commit: `37c52d208bdddd161a1d26cbdb0548cb251ca877`
- filtered cutover commit: `ca20eb1aa7`

Retained paths include the Rust workspace, PHP Runtime, TypeScript routing/WASI
host, finalizer parity harness and the Builder/Runtime architecture documents.
Spacefast control-plane, dashboard, wp.cloud and Railway application code were
not copied.
