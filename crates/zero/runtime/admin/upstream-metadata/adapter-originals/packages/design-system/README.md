# @zero-admin/design-system

[![Storybook]([upstream private reference omitted])]([upstream private reference omitted])

> [!WARNING]
>
> **This package is deprecated, and you should use components from `@wordpress/ui` instead.**

`@zero-admin/design-system` was a package of design system component implementations built and iterated as part of the Zero Admin application.

Since early 2026, primary development of these components has moved to [Gutenberg's `@wordpress/ui` package](https://github.com/WordPress/gutenberg/blob/trunk/packages/ui/README.md).

This package now serves as a staging area for components which are pending migration to `@wordpress/ui`.

For more information, see:

-   [WordPress Design System in CIAB: Current Technical Guidance and What’s Next]([upstream private reference omitted]) (+ciabp2 P2 post)
-   [ARC-1359: Migrate components from zero-admin to Gutenberg]([upstream private reference omitted]) (Linear tracking issue for migration)
